How I Started Coding

By Princess Essiam • January 11, 2026 • 3 min read • Engineering

Every developer remembers the moment they wrote their very first program. For me, it started with a simple, blank text document and a handful of HTML tags.

"Seeing those words render inside the web browser felt like magic. It wasn't just viewing web content anymore—it was creating it."

I saved my first snippet as an index.html file and opened it in Google Chrome:

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>My First Web Page</title>
</head>
<body>
    <h1>Hello World</h1>
    <p>Welcome to my software engineering journey.</p>
</body>
</html>

From that single heading, I was hooked. I quickly progressed to CSS to understand how colors, typography, flexboxes, and responsive grids give structure and personality to websites.

Lessons Learned Along the Way

Programming is less about memorizing syntax and much more about learning how to break down complex problems into solvable steps. Early on, I would get stuck on misplaced brackets or missing semicolons for hours. Over time, debugging became second nature.

If you are at the start of your tech journey, remember that patience and consistent daily practice are your greatest tools.
